evaluator approach, the correctness/performance scores achieved by each AI-driven
optimization system that has been run against EvolveBench (e.g. OpenEvolve,
ShinkaEvolve, AlphaEvolve-style agents).

## Submitting a result

1. Add or update an `integrations/<system>/` folder with the exact runner/config
   used, following the pattern in `integrations/openevolve/`.
2. Report, per task: the evaluator approach, iteration/compute budget, model(s)
   used, and the resulting correctness/performance/combined scores.
3. Open a pull request adding a row to the table below (or propose the table format
   if this is the first submission for a new system).
